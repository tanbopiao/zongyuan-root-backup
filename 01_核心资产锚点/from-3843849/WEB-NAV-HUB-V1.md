## 一、机制定位

将 ZONGYUAN-ROOT 体系全部网页资源：
- **自动扫描**：知识库文档链接、台账链接、官网门户、作品库、真值库、云盘
- **导航图谱**：按域分类构建互联导航图谱（官网/知识库/台账/云盘/真值）
- **枢纽页生成**：生成全域互联导航枢纽 HTML（一键触达所有资产）
- **验证沉淀**：链接可访问性抽查 + 真值上报 + 锁档

**打通链路**：官网门户 ⇄ 作品库 ⇄ 知识库 ⇄ 台账 ⇄ 云盘 ⇄ 真值库——一个枢纽页全联通。

---

## 二、四阶段链路（NAV-4）

```
P1 资源扫描 → P2 导航图谱 → P3 枢纽页生成 → P4 验证沉淀
 (链接采集)   (域分类)     (HTML枢纽)     (可访问性+真值)
```

### P1 资源扫描
- 本地机制文档抽取知识库链接
- 台账 200 条记录抽取全部 wiki 链接
- 核心网页资源锚定（官网门户/作品库/台账/云盘/知识库/真值库/SOP入口）

### P2 导航图谱
- 按域分类：官网门户 / 知识库 / 台账 / 云盘 / 真值库
- 核心机制文档优先标注

### P3 枢纽页生成
- 指标区：全网关链接数 / 核心锚点 / 知识库文档 / 机制文档
- 核心锚点区：7 大核心网页一键触达
- 机制知识库区：核心机制文档直达
- 全域知识库区：完整档案（可折叠）

### P4 验证沉淀
- 链接可访问性抽查（HTTP 200）
- 真值上报：`WEB-NAV-HUB-YYYYMMDD-HHMM`
