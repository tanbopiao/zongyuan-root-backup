## 第一部分：海外免费 GPU（免信用卡，需访问 Google 系服务）

### 1. Google Colab（最经典）
- **额度**：免费版每周约 15-30h，T4 16GB
- **限制**：单会话最长 12h；空闲 90 分钟断连；会话结束数据清空（可挂载 Google Drive）
- **申请步骤**：
  1. 注册/登录 Google 账号（需能访问 Google 服务）
  2. 打开 https://colab.research.google.com → 新建笔记本
  3. 菜单 代码执行程序 → 更改运行时类型 → 硬件加速器选 GPU（默认 T4）
  4. 在代码单元格跑 `!nvidia-smi` 验证 GPU
- **用途**：快速试跑、小模型训练、学习

### 2. Kaggle Notebooks（最稳定免费）
- **额度**：每周 30h GPU（P100 16GB），保证可用
- **限制**：单会话 9h；无付费升级通道
- **申请步骤**：
  1. 注册 https://www.kaggle.com（Google 账号或邮箱）
  2. 新建 Notebook → Settings → Accelerator 选 GPU P100
  3. 连接后直接跑代码，每周配额自动重置
- **用途**：竞赛、轻量微调、稳定白嫖

### 3. Lightning AI（开发环境最专业）
- **额度**：每月 80h GPU（T4/L4），VS Code 式工作区
- **限制**：需手机号验证
- **申请步骤**：
  1. 注册 https://lightning.ai（邮箱+手机验证）
  2. 免费档每月 15 credits ≈ 80h T4
  3. 创建 Studio 实例选择 GPU 即可
- **用途**：专业开发环境、长任务

### 4. Hugging Face ZeroGPU（免费卡皇）
- **额度**：免费配额，**H200 70/141GB 显存**（全网免费最强）
- **限制**：配额受限，用于 Spaces 应用托管
- **申请步骤**：
  1. 注册 https://huggingface.co（邮箱）
  2. 创建 Space → 硬件选 ZeroGPU（免费）
  3. 部署你的推理应用，自动获得共享 H200
- **用途**：大模型推理托管、Demo

### 5. Thunder Compute 学生档
- **额度**：学生邮箱注册送 **$20 免费额度**（A6000/A100 可用）
- **限制**：需 .edu 等高校教育邮箱
- **申请步骤**：
  1. 用学校邮箱注册 https://www.thundercompute.com
  2. 通过学生验证后 $20 自动到账
  3. 按需开 A6000（$0.35/h）约可跑 57h
- **用途**：零成本试水付费级 GPU

### 6. AMD Developer Cloud
- **额度**：$100 信用值 / 30 天，**MI300X 192GB**
- **限制**：需填表审核 2-3 个工作日；适合 ROCm 生态

### 9. 腾讯 Cloud Studio（❌ 已确认不推荐，2026-09-18 全网交叉验证）
- **交叉验证结论**：腾讯云官方文档（购买指南/机时FAQ）+ cloudstudio.net 帮助中心 + CSDN 社区实测（2026-09-11）多方一致——老版入口已停服，新版免费额度缩水且存在自动转付费风险，对免费党不推荐
- **免费额度（仍存在但缩水）**：每月 1 号送 CPU 10000 分钟体验时长 + GPU 3600 分钟（限免费基础型 T4）；每日签到领 2 机时（7 天有效）；首次绑定腾讯云账号赠 20 机时

## 通用申请避坑要点

1. **同人判定**：平台通过身份证/手机号/设备等多维判定，注册小号反复领会被封——每产品一次机会，先规划再领取
2. **"新用户"定义**：指未买过该产品，不是账号新注册；RAM 子账号不能领，须主账号操作
3. **停机≠停计费**：阿里云 ECS/PAI 停止实例仍可能计费，**必须"释放/删除"**
4. **额度≠时长**：GPU 算力按"计算时"扣费（A10 每小时扣 6.99 计算时，250 计算时只够 35h）
5. **先领后用**：阿里系产品（PAI-DSW 等）必须先领试用权益再使用，用过就不能领了
6. **免费额度有期限**：多数月底/到期清零，不结转不补发；领了要规划用完
