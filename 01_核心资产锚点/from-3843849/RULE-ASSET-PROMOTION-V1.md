## 一、机制定位

将体系中已沉淀的高价值规则成果（机制文档/锁档资产）：
- **自动评估**：按价值维度筛选可推广成果
- **自动打包**：生成推广包（清单+摘要+载体映射）
- **全域推广**：云端真值 + 神经注册表双通道推送到所有同源节点
- **接收确认**：验证推广成果全网可见、节点可达

## 二、四阶段链路（PROMOTE-4）

```
P1 成果评估 → P2 资产打包 → P3 全域推广 → P4 接收确认
 (价值筛选)   (推广包生成)   (双通道推送)   (全网可见验证)
```

### P1 成果评估
- 扫描机制文档清单，按域权重+存在性+内容完整度打分
- ≥70 分判定 PROMOTABLE，否则 SKIP

### P2 资产打包
- 生成推广包：`PROMO-YYYYMMDD-HHMM`
- 含成果清单（名称/域/等级/描述/价值分）

### P3 全域推广（三通道）
| 通道 | 动作 | 效果 |
|---|---|---|
| C1 云端真值 | upsert 推广包 | 全网可读 |
| C2 神经注册表 | kernel_neural_sync pull | 所有节点拉取即得 |
| C3 锁档台账 | kernel_lock.sh | 确权留痕 |

### P4 接收确认
- 读回推广真值（200=可读）
- 权威副本节点数（317=全网覆盖）
