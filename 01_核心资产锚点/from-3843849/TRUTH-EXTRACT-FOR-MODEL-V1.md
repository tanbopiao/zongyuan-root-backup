## 一、机制定义

**输入**（4 源）：
1. 云端中枢真值快照（internal 4664 + public 4586，gateway 恢复时拉最新 14508）
2. 锁档台账（base 199 条结构化事实）
3. 核心资产 JSON（能力注册表/元法则注册表/同源协议库/经验教训/成功轨迹）
4. 关键机制文档（SOP/闭环标准/最大化方案/基准锚点）

**处理**（4 阶段）：
1. **收集**：4 源合并去重
2. **分类**：8 类高价值分类（公理元法则/协议/机制/成果/安全/教训/演化/运行）
3. **质量评估**：权重×质量分（结构化+长度+语义密度）
4. **蒸馏**：阈值过滤（权重≥3.5 且质量≥3）→ 生成 JSONL 训练语料 + 规则集

**输出**：
- `model_training/truth_training_corpus_YYYYMMDD.jsonl`（训练语料，instruction/output 格式）
- `model_training/truth_rules_YYYYMMDD.json`（规则集，含类别分布/TOP20）

## 二、高价值判定标准（训练优先级）

| 类别 | 权重 | 训练价值 |
|---|---|---|
| 公理/元法则 | 5 | 最高——体系规则核心 |
| 协议/握手 | 4.5 | 节点协同规则 |
| 机制/流程 | 4 | 可复用执行模式 |
| 安全/凭证 | 4 | 安全语料 |

| 成果/锁档 | 3.5 | 演进轨迹 |
| 演化/优化 | 3 | 自进化知识 |
| 运行日志 | 2 | 低价值（默认过滤） |
