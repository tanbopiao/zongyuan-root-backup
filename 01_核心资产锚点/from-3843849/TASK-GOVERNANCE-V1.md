## 一、机制定位

让任务体系自我治理：
- **价值评估**：每个定时任务按四维打分（VALUE-4）
- **自动合并**：同域同频低效任务自动合并，释放配额
- **自动构建**：检测空白核心域，自动生成高价值任务提案
- **配额守护**：10 任务上限内的最优配置

---

## 二、价值评估四维（VALUE-4）

```
任务价值 = V1体系贡献度 + V2频率匹配度 + V3资源效率 + V4不可替代性
（每维 1-5 分，满分 20 → 百分制）
```

| 维度 | 评估内容 | 权重逻辑 |
|---|---|---|
| V1 体系贡献度 | 域权重：kernel/homology/neural/sandbox=5，cloud/sop/archive=4，asset/meta=3 | 核心域优先 |
| V2 频率匹配度 | 实际频率 vs 域时效需求 | 匹配=5，近匹配=4，偏离=2 |
| V3 资源效率 | 高频轻量任务得分高 | 30m=5，6h=4，daily=3 |
| V4 不可替代性 | 同域同频重叠度 + 内嵌能力数 | 独有=5，重叠降分，内嵌能力加分 |

**等级判定**：≥16 分 HIGH（保留）｜12-15 分 MED（观察）｜<12 分 LOW（合并/剔除）

---

## 三、自动合并规则

```
同域(domain) + 同频(freq_group) 任务 ≥2 个
        ↓
合并为单一批次任务（保留全部脚本调用）
        ↓
释放 (N-1) 个配额 → 用于高价值新任务
```

---

## 四、自动构建规则

```
检测 域覆盖 + 能力覆盖（含内嵌能力）
        ↓
空白核心域 → 生成高价值任务提案
        ↓
HIGH 优先级：安全审计（security 域空白）
MED 优先级：契约一致性校验（contract 空白）
```
