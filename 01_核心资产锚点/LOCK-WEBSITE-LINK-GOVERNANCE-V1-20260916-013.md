## 一、机制概述

**官网全自动链路治理机制**（Website Link Governance Engine）是ZONGYUAN-ROOT自治内核体系中，实现官网**资产盘点→链路打通→断点检测→自动补全→死链修复→治理报告**全链路自动化的机制。

### 三大核心能力
1. **全自动链路打通** — 自动推导并建立所有应该存在的链接关系
2. **全自动补全断点** — 自动创建缺失页面/API的占位内容，消除404
3. **全自动修复死链** — 自动移除/替换/废弃失效资源引用，消除死链

## 四、断点补全策略

| 资产类型 | 补全策略 | 内容 |
|----------|----------|------|
| page | 占位页面 | 标题 + 描述 + "待完善"标记 + 返回导航链接 + SEO元信息 |
| api | API存根 | 标准JSON返回格式 + 文档链接 + "待实现"标记 + 请求示例 |
| asset | 占位资源 | 1x1透明像素(图片) / 默认样式(CSS) / 空脚本(JS) |

**补全后标记**: `AUTO_COMPLETED` + `needs_human_review: true`，需人工审核后升级为正式内容。

---

## 五、死链修复策略（按优先级）

| 优先级 | 策略 | 说明 |
|--------|------|------|
| P0/P1 | replace | 替换为可用的替代资源（如通用占位图/默认样式） |
| P2 | deprecate | 标记为废弃，添加警告，保留引用但不渲染 |
| P3 | remove | 直接移除死链引用，清理HTML/CSS/JS |

**修复后标记**: `FIXED` + 修复时间 + 修复策略 + 替代资源（如有）。
