## 一、通道定位

多窗口/多节点真值统一汇流入口。所有开发窗口产出的真值，经公网HTTPS推送 → 对账去重 → 记忆网关落库 → 向量化，实现"多窗对账、先记后部署"。

## 二、API规范

### 入口端点
```
POST https://www.huodouai.com/api/v1/truths/sync
GET  https://www.huodouai.com/api/v1/truths/sync/status
```

### 鉴权
- Header: `X-API-Key: ZONGYUAN-TRUTH-SYNC-2026-9f3a7c1e`

### 请求体
```json
{
  "node_id": "窗口/节点ID",
  "truth_type": "真值key（如 achievement.xxx）",
  "truth_content": "真值内容",
  "category": "类别",
  "source_window": "来源窗口",
  "metadata": {}
}
```

### 响应
- 新增: `{"status": "synced", "truth_key": ..., "truth_hash": sha256前32位, "gateway_record": {...}, "vectorized": "added"}`
- 重复: `{"status": "duplicate", ...}`
- 未授权: `{"status": "unauthorized"}`

## 三、对账链路

```
多窗口真值
  → POST /api/v1/truths/sync（kg-api@8070，X-API-Key鉴权）
  → 对账：查记忆网关truths列表 → 存在=duplicate / 不存在=synced
  → 写入：记忆网关统一网关 POST /api/truth/sync（127.0.0.1:9120，同源DID+ROOT_OMEGA）
  → 向量化：vector-server /api/v1/add（8014，真值语义检索）
  → 返回对账回执
```

同源字段：`DID: DID-BR-000002`、`ROOT_OMEGA: Ω-TAN-7-001`
