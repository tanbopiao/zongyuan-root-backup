调度引擎自动统计每一类任务的 Token 与资源消耗，遵循五维约束（价值、收益、成本、风险、稳态）动态维持产能稳态。

故障熔断降级

闭源 API 限流、调价、接口变更或超时，自动降级切换至本地开源基座，流水线不中断，异常事件写入审计台账。

熔断降级 · 零中断

资产安全隔离

私有剧本、未发布 IP 素材、内核元规则、密钥凭证等敏感任务，强制路由本地开源模型，禁止传入第三方闭源 API。

敏感资产 · 强制本地

每次路由决策、任务分发、资源消耗生成真值记录，纳入全域扫描与审计巡检，同步 9120 记忆网关，全程可追溯。
