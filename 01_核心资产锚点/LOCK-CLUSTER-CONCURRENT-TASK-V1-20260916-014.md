## 四、集群组织架构

### 4层分层模型
```
┌─────────────────────────────────────────────┐
│  L0_MASTER  主节点层 (1节点)                 │
│  全局决策 + 任务分配 + 最终一致性仲裁         │
├─────────────────────────────────────────────┤
│  L1_COORDINATOR  协调节点层 (3节点)          │
│  内核域协调 + 神经域协调 + 运维域协调         │
├─────────────────────────────────────────────┤
│  L2_WORKER  工作节点层 (8节点)               │
│  内核读取/自检/纠错 + 神经激活/分析 +        │
│  元进化 + 监控/同步                           │
├─────────────────────────────────────────────┤
│  L3_MONITOR  监控节点层 (2节点)              │
│  集群健康监控 + 性能分析监控                  │
└─────────────────────────────────────────────┘
```

### 通信拓扑
- **星型**: 主节点 ↔ 协调节点（3条）
- **树形**: 协调节点 → 工作节点（7条，按域匹配）
- **网状**: 同域工作节点 ↔ 工作节点（5条）

### 组织原则
- 分层组织 + 域内自治 + 全局协调 + 弹性伸缩
- 下级执行上级决策，上级聚合下级结果
- 同层节点可直接协作（网状通信）

## 五、并发任务调度机制

### DAG任务分解
- 将复杂任务分解为有向无环图(DAG)子任务
- 自动分析依赖关系，计算执行波次
- 无依赖的子任务可并行执行

### 负载感知调度
- 按域匹配：优先分配给同域工作节点
- 负载最低优先：同域内选择负载最低的节点
- 动态调整：分配后更新节点负载，避免热点

### 波次并发执行
- 同一波次内所有子任务并发执行
- 波次间严格按依赖顺序执行
- 最大并发数 = 最大波次内子任务数
